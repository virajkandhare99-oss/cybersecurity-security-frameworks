## 1. CIA Triad

The CIA Triad represents three fundamental objectives of information security:

### Confidentiality
Ensuring that information is accessible only to authorized individuals.

### Integrity
Ensuring that information remains accurate, complete, and has not been
modified without authorization.

### Availability
Ensuring that systems and information are available to authorized users
when required.

---

## 2. Security Frameworks

Security frameworks provide structured guidelines and best practices for
managing cybersecurity risks.

Examples include:

- NIST Cybersecurity Framework
- ISO/IEC 27001
- CIS Controls

---

## 3. Security Controls

Security controls are safeguards used to reduce security risks.

Examples:

- Access control
- Authentication
- Encryption
- Network segmentation
- Security monitoring
- Backups

---

## 4. OWASP

OWASP (Open Worldwide Application Security Project) provides resources,
guidance, and security knowledge related to application security.

Topics studied include common web application security risks and secure
development principles.

---

## 5. Security Audits

A security audit is a systematic examination of an organization's
security controls, policies, procedures, and systems.

A basic audit process can include:

1. Define the scope
2. Identify security requirements
3. Review existing controls
4. Identify gaps
5. Assess risks
6. Document findings
7. Recommend improvements
8. Follow up on remediation

# Sample Security Audit

## System

Example Web Application

## Scope

Authentication and access control.

## Findings

### Finding 1 — Weak Password Policy

Risk: Medium

Description:
The application allows users to create weak passwords.

Potential Impact:
Attackers may perform password-guessing attacks.

Recommendation:
Implement a strong password policy and MFA.

---

### Finding 2 — Missing Account Lockout

Risk: High

Description:
The application does not adequately restrict repeated failed
authentication attempts.

Potential Impact:
Increased risk of brute-force attacks.

Recommendation:
Implement rate limiting and account protection mechanisms.
